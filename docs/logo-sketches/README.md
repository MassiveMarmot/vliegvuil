# VliegVuil logo sketches

Five quick SVG concept sketches, aligned with the project theme (docs/SPEC.md):
warm coral-to-red noise-gradient palette, rounded friendly plane glyph (not sharp
radar chevrons), contour-band imagery.

| File | Concept |
|---|---|
| `sketch-1-contour-plane.svg` | Rounded plane flying out of concentric noise-contour rings |
| `sketch-2-noise-bands.svg` | Plane rising over stacked Lden contour bands |
| `sketch-3-badge.svg` | Circular app-icon badge: half contour rings, half sky, plane crossing the boundary |
| `sketch-4-map-pin-trail.svg` | Dotted live-map flight trail curving into a noise-contour blob over a Netherlands hint |
| `sketch-5-airline-livery.svg` | Airline-livery style: gradient tail fin with cheatline sweep, spaced-caps wordmark |

All files are small, hand-editable SVGs; wordmarks use system-ui as a stand-in
(the site ships no third-party fonts, so a final logo should keep that constraint).
